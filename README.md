# 🚀 QA Login Automation

Projeto de automação de testes utilizando Cypress para validação de login em aplicação web.

---

# 🧪 Tecnologias

- Cypress
- JavaScript
- GitHub

---

# 📌 Cenários automatizados

✅ Login com sucesso  
✅ Login inválido  
✅ Validação de mensagens de erro  
✅ Fluxo de autenticação  

---

# ▶️ Como executar

```bash
npm install
npx cypress open
```
